About & Web Concepts

A short, practical tour of the foundational Web Programming concepts this project is built on. Full explanations and setup notes live in the project README.md. This particular page is a static client-side build — the real app's version is about.php.

The World Wide Web, in brief

The World Wide Web began in 1989 as a way to share linked documents over the Internet; it has since evolved from static pages to the dynamic, database-backed applications like this tracker. Related Internet services include Email (message delivery via SMTP/IMAP), Telnet (remote terminal access), and FTP (file transfer) — all predate the Web but still run over the same Internet infrastructure. Modern uses built on top of the Web include e-commerce, cloud computing (renting storage/compute instead of owning servers), and video conferencing.

How a request reaches this application

  • ISP (Internet Service Provider): the company that connects your device to the Internet backbone.
  • IP address: the numeric address (e.g. 127.0.0.1) a server is reached at.
  • URL: a human-readable address such as http://localhost/deadline-tracker/index.php that identifies a resource.
  • DNS (Domain Name Server): translates a domain name into the IP address it maps to.
  • Web browser: the client that sends HTTP requests and renders the HTML/CSS/JS response (Chrome, Firefox, Safari...).
  • Search engine: a separate service (e.g. Google) that crawls and indexes pages so users can find them by keyword.

Web server vs. application server

A web server (Apache, Nginx, or PHP's built-in server) accepts HTTP requests and returns static files or hands dynamic requests off for processing. An application server executes the business logic — here, that's PHP reading/writing the tasks table via PDO. In this project PHP's built-in development server plays both roles locally. (This particular static page has no application server at all — everything runs in the browser.)

ReactJS vs. React Native

ReactJS renders to the browser DOM and is used for web applications — see the react-demo/ folder in this project. React Native uses the same component/JSX model but renders to native mobile UI components (iOS/Android) instead of the DOM, and is not used anywhere in this project since it targets mobile apps, not the Web.
